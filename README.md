# Landing Page Convite Etraction

Projeto React/Vite com arquivos separados.

## Rodar localmente

```bash
npm install
npm run dev
```

## Build para GitHub Pages

```bash
npm run build
```

O build sai em `docs/`.

## Logo

O arquivo da logo fica em:

```text
public/logo-etraction.svg
```

## Google Forms

Configuração em:

```text
src/config/googleForm.js
```
